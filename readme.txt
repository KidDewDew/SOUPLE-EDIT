SoupleEdit 嗖谷文档编辑软件的源程序位于本目录。
----- 本项目包含 -----
1.嗖谷文档编辑软件
2.小灵通PDF编辑APP(android版本)
3.SouplePDF库
4.SouplePDF各种后端服务程序
----- 文件夹说明 -----
/lib
·····存储使用的库(静态库+头文件);
/auto_copy_dll
·····存储程序依赖的dll库，编译时自动由cmake拷贝到程序旁边;
/Shader
·····存储着色器文件;
/back-fonts
·····存储SoupleEdit使用的附加缺省字体，编译时自动由cmake负责拷贝;
/android
·····小灵通PDF编辑app的android目录;
/souple_pdf
·····SouplePDF库工程;
/SoupleService_<serviceName>
·····SouplePDF后端服务;
